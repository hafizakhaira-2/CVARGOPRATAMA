# CVARGOPRATAMA
**CV ARGO PRATAMA** adalah Logistik dan expedisi pengiriman kendaraan niaga yang menyediakan berbagai pilihan armada seperti mobil box, box lift pengangkat barang, blind van, dan pick up. Kami hadir untuk mendukung kebutuhan distribusi, logistik, dan operasional bisnis dengan solusi kendaraan yang praktis, andal, dan sesuai kebutuhan.
